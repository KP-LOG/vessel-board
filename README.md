# 모선 일정 변경 확인판

부산 북항 터미널(허치슨 · 신선대 · 감만) 선석배정현황을 조회해, 추적 중인 모선의 입항(접안)·출항 예정시간이 마지막으로 안내한 시간과 달라지면 바로 보여주는 업무용 도구입니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 확인판 화면. 모선 추가, 변경 감지, 시간 점검, 안내 초안, 알림 연결 |
| `선석조회.py` | 터미널 선석배정현황 조회 → `선석데이터.js` 생성, 추적 모선 변경 시 Windows 알림 |
| `선석조회.bat` | 조회 프로그램 실행 (작업 스케줄러로 1시간마다 실행) |
| `선석데이터.js` | 조회 결과 (터미널 공개 일정 스냅샷) |
| `문제정의_모선일정변경확인판.md` | 문제 정의서 (주제·가설·인터뷰·문제 정의·성공 기준) |

## 조회 대상 (로그인 불필요 공개 화면)

- 허치슨: https://custom.hktl.com/jsp/T01/sunsuk.jsp
- 신선대·감만(BPT): https://info.bptc.co.kr/content/sw/frame/berth_status_text_frame_sw_kr.jsp?p_id=BETX_SH_KR&snb_num=2&snb_div=service (조회기간 일주일)

## 사용 방법

1. PC에서 `선석조회.bat`을 실행하거나 작업 스케줄러에 1시간 주기로 등록합니다.
2. `index.html`을 열고 [+ 모선 추가]로 모선명·항차·터미널을 넣으면, 조회 결과에서 선명으로 찾아 시간을 채웁니다.
3. 시간이 바뀌면 '확인이 필요한 모선'으로 올라오고, [🔍 시간 점검]으로 한 번에 점검할 수 있습니다.
4. [🔔 알림 연결]로 `추적모선.json`을 같은 폴더에 저장하면, 조회 프로그램이 변경 시 Windows 알림을 띄웁니다.

## 유의 사항

- 웹(Vercel)에 올라간 `선석데이터.js`는 업로드 시점의 스냅샷입니다. 최신 일정은 PC에서 조회 프로그램을 실행해야 반영됩니다.
- 입력한 모선 목록은 각자의 브라우저에만 저장되며 서버로 보내지 않습니다.
- 표시된 시간은 조회 시점 기준 예정시간입니다. 안내 전에 터미널 화면에서 다시 확인하세요. 안내 초안은 초안일 뿐이며 발송은 사람이 직접 합니다.
